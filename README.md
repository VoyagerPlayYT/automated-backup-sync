## 🌟 Описание проекта

**Automated Backup & Sync Agent** — это надежная инженерная система защиты данных от случайного удаления, повреждения диска или атак вирусов-шифровальщиков.

Утилита обеспечивает регулярное сжатие важных семейных файлов (документов, баз данных, настроек умного дома) в компактные ZIP-контейнеры с расчетом контрольной суммы.

### Ключевые возможности:
- 🚀 **Два режима работы**:
  - `Web Dashboard`: удобный графический интерфейс управления с кнопкой мгновенного создания бэкапа и скачиванием архивов.
  - `CLI Mode`: быстрый запуск через консоль или планировщик ОС (`python backup_agent.py --run-now`).
- 🔒 **Криптографический аудит (SHA-256)**: каждый созданный архив сопровождается хэшем. Кнопка «🛡️ Тест» сверяет биты архива с контрольной суммой и проверяет CRC32 каждого файла.
- ♻️ **Политика удержания (Retention Policy)**: система автоматически сохраняет 5 самых свежих версий, удаляя устаревшие и не засоряя свободное место на диске.
- 📜 **Журнал аудита в SQLite**: точная дата, время, размер в байтах и количество сохраненных файлов.

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, zipfile (сжатие deflate), hashlib (SHA-256), SQLite3
- **Frontend**: HTML5, Tailwind CSS в защищенном темном стиле Security Vault, Vanilla JavaScript
- **Архитектура**: Универсальный гибридный агент (CLI + RESTful Web API)

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Резервное копирование — это ключевая задача, ради которой во всем мире устанавливают домашние сервера:

1. **Тихое ночное архивирование в 03:00 без участия человека**:
   - Рабочий компьютер днем загружен играми или программами, а ночью выключен. Выделенный сервер 24/7 делает бэкапы глубокой ночью, когда домашняя сеть свободна, и к утру гарантирует сохранность данных.
2. **Изоляция архивов от вирусов на основном ПК**:
   - Если рабочий компьютер поймает вирус или повреждение операционной системы, резервные копии на отдельном сервере останутся в полной безопасности.
3. **Безопасное хранение семейных архивов за 10–20 лет**:
   - Сервер с зеркальными дисками (RAID-1) гарантирует, что памятные фотографии, домашние видеозаписи и сканы документов родителей не пропадут даже при физическом выходе одного из накопителей из строя.
